# SIE-Agent identity

The icon pairs a research paper with an extracted data table and the visible
name **SIE Agent**. White, black and vermilion establish the hierarchy: source
document, extraction action, structured result.

The visual reference was the [ScanSci PDF project icon](https://github.com/Rimagination/scansci-pdf/blob/main/assets/brand/scansci-pdf-icon.png):
readable naming, high contrast and a direct explanation of the tool's purpose.
The SIE-Agent composition instead depicts paper-to-table extraction. The
reference asset is not distributed with this repository.

- `public/sie-agent-icon-v2.png`: primary project and touch icon.
- `public/favicon.svg`: simplified vector adaptation without the wordmark,
  for small browser tabs.
- Colors: white `#ffffff`, black `#111111`, vermilion `#ea3323`.
- Method: built-in `imagegen`, using the public reference image for style.
  No project API credentials or institutional materials were used.

## Generation prompt

> Use case: logo-brand. Create a NEW finished project icon for SIE-Agent, scientific information extraction from research papers into structured tables. The attached ScanSci icon is a STYLE REFERENCE ONLY: learn its high-contrast white/black/red palette, prominent readable product naming, and very clear research-tool function. Do not reproduce its logo layout, magnifying glass, download arrow, PDF label, or the ScanSci name. Build an original SIE-Agent identity.
>
> Design: a crisp white square app tile with gently rounded corners and an extremely subtle light-gray edge. The main symbol, occupying the upper two thirds, is a heavy black outline of a scholarly paper on the LEFT transitioning into a neatly organized vermilion-red DATA TABLE on the RIGHT. The paper has a folded corner and just two short black text lines. Its right edge opens toward the table; one short bold red right-pointing extraction arrow bridges them. The table is a compact red 2-column by 3-row rectangle with an unmistakable header bar and white grid dividers, optically balanced with the paper. This must read at a glance as paper-to-structured-data, with no scattered dots or circuit branches.
>
> Brand naming is essential: BELOW the symbol, as part of the icon, put the exact text 'SIE' in very large, bold, beautifully spaced black geometric sans-serif capitals, followed by the exact text 'Agent' on the same baseline in a slightly lighter but still bold weight. The complete wordmark reads 'SIE Agent'. Make the wordmark occupy about 78 percent of the canvas width and visibly legible when the full icon is shown at 144 pixels. Align symbol and wordmark as one compact composition with generous, deliberate margins. Black #111111, vermilion #EA3323, white #FFFFFF only; flat crisp vector-like artwork. The hierarchy must be stronger and more intentional than a stock UI icon. No decorative texture, no teal, no mint, no gradients, no 3D bevel, no glossy effects, no extra text, no institution/school marks, no presentation sheet. One high-quality square icon, fully opaque white background.
