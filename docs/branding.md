# SIE-Agent icon

The mark connects a document to structured data: ivory source material and mint
extraction nodes on a dark teal background. It uses no institutional imagery,
personal identity or private source material.

- `public/sie-agent-icon.png`: generated primary icon used in the README and as
  the touch icon.
- `public/favicon.svg`: a compact, editable vector adaptation for browser tabs.
- Colors: dark teal `#173d41`, ivory `#f2faf6`, mint `#91e5cf`.
- Generation method: the built-in `imagegen` tool; no project API credentials
  were used.

## Generation prompt

> Use case: logo-brand. Create one finished square app icon for SIE-Agent, an
> open-source scientific document information extraction workspace. The icon
> must be original and must not reference any institution, school, existing logo
> or person. A premium, very simple flat geometric mark, immediately legible at
> 32 px: one softly squared ivory document outline with a small folded
> upper-right corner, two short horizontal evidence lines within it, and one
> mint highlighted information block extending out to the right into a compact
> structured-data motif. Integrate the document and extracted block into one
> balanced, memorable silhouette; no separate floating decorative elements.
> Deep dark teal background (#173d41) as a rounded-square tile, warm ivory
> (#f2faf6) and luminous mint (#91e5cf) symbol. Centered, generous internal
> margins, consistent bold line weight, precise geometry, calm research software
> identity. Flat vector-like appearance, no gradients, no 3D, no shadows, no
> texture, no mockup, no border framing, no text, no letters, no watermark.
> Exactly one icon filling a 1024x1024 canvas; transparent pixels only outside
> the rounded-square tile corners. Deliver the actual icon asset, not a
> presentation board.

## Final refinement prompt

> Edit this app icon. Preserve the exact foreground geometry and arrangement:
> the ivory document outline, its two text strokes, and the mint extraction/data-node
> symbol. Change ONLY the background and surface finish. Replace the ENTIRE
> canvas background, including ALL four corners and the interiors of the icon,
> with perfectly uniform fully opaque flat solid dark teal RGB(23,61,65),
> #173d41. Fill every accidental black or transparent hole and remove every
> mottled or textured patch. There must be NO transparency at all anywhere in
> the output. The final image is a fully opaque SQUARE image with dark teal
> extending to all canvas edges, not a rounded tile cutout. Render the foreground
> in perfectly uniform flat ivory #f2faf6 and mint #91e5cf, retaining crisp
> anti-aliased edges. No gradients, noise, blur, shadows, texture, letters or
> extra elements. This is a precise flat software brand icon asset, not a photo.
