# Synthetic examples

All example content is fictional and is generated by
`scripts/generate-examples.py`. It is not a scientific publication or a source
of research findings.

- `synthetic-study.pdf`: eleven pages of fictional soil-particle observations,
  generic tables and coordinate-grid graphics for demonstration and PDF tests.
- `extraction-template.xlsx`: a newly generated workbook containing only
  seventeen generic extraction column headers.

Neither file contains original user documents, institution names, credentials,
real author names or original document metadata. The generated content is
covered by the project's MIT license.
